How it works

难的不是动画，是把坐标系钉死

分层变换，而不是换图

头 / 上身 / 下身三层用 clip-path 切分、各自独立变换。呼吸挂一层、拖拽物理挂一层、注视挂各层图片——互不干扰。

九帧共用一套坐标系

水平对红帽质心、垂直对鞋底共线、尺度按 alpha 轮廓归一。不统一的话，切帧时整个人平移加缩放，看起来像信号不良。

抠图是真正的脏活

模型输出的「透明背景」其实是画进像素的棋盘格；马尾和身体还会围出封闭口袋。这些坑都写进了 README。

Get started

两分钟跑起来

需要 Node.js 18+ 和一个麦当劳 MCP Token（open.mcd.cn 免费申请）。

# 1. 克隆
git clone https://github.com/For-Chance/mcd-desk-mate.git
cd mcd-desk-mate

# 2. 安装依赖
npm install

# 3. 填入 Token（Windows 示例）
setx MCD_MCP_TOKEN "你的Token"

# 4. 让麦娘上岗
npm start

想先看效果不装环境？README 里有全部真实截图与动图，以及 12 个 MCP Tool 的实测输出。
